# UI Kit — Marketing-Website

Öffentliche Website von Fluer Development, eine Seite: Hero, Leistungen, Arbeit (Zeilenliste statt Kartenwand), Kontaktband auf dunkler Fläche, Footer.

Dateien: `SiteChrome.jsx` (Header mit Glass-Effekt + Footer), `HomePage.jsx` (alle Sektionen), `index.html` (Mount, Anker-Navigation).

Regeln, die diese Fläche zeigt: 1280px Container mit 32px Gutter, 96px Sektionsabstand, genau ein Primary-Button pro Sektion, Teal nur auf Buttons/Icon-Flächen, ein einziger dunkler Block (Kontakt) als Abschluss.

Kein Logo vorhanden — die Wortmarke ist gesetzter Text ("Fluer" + Punkt in --blue-500).
