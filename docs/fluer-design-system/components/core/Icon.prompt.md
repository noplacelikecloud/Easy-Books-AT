One-line: the only icon primitive in the system — a Lucide glyph inlined as SVG and tinted with currentColor, used inside buttons, nav items, badges and empty states.

```jsx
<Icon name="cloud-upload" size={16} />
```

Notes: icon slugs are Lucide names (kebab-case). Sizes in use: 14 (inline/label), 16 (buttons, nav), 18 (default), 20-24 (empty states, feature marks). Never colour an icon directly — set colour on the parent.
