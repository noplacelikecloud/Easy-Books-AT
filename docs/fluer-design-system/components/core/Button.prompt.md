One-line: the action control — one primary button per view, everything else secondary or ghost.

```jsx
<Button variant="primary" size="md" iconAfter="arrow-right">Projekt anlegen</Button>
```

Variants: primary (deep teal fill, the single main action), secondary (white + hairline border), ghost (toolbar / table-row actions), danger (destructive, text-red on white — never a red fill). Sizes sm/md/lg. Press state nudges 0.5px down; no scaling, no bounce.
